# Original Watch Media Submission Template

This template is for the final gallery-media handoff. Please submit **original or explicitly rights-cleared files only**. Social screenshots, watermarked composites, publisher graphics, and product renders without permission should be treated as research leads, not gallery media.

## One Row Per Image

| File name | Exact archive record ID or watch name + reference | Image type | Rights confirmation | English caption (optional) | Arabic caption (optional) |
|---|---|---|---|---|---|
| `example-rm68-detail.jpg` | `60025 — Richard Mille RM 68-01 Tourbillon Cyril Kongo` | `detail` | `I own this image` or `Written permission attached` | Detail of the movement and dial | تفصيل للمينا والحركة |

Allowed image types are **studio**, **wrist**, **detail**, and **movement**. The secure administrator workflow accepts JPEG, PNG, and WebP files up to 12 MB each, with up to eight files per upload batch.

## Rights and Association Confirmation

For each uploaded file, confirm both statements below:

> I am authorized to use this image in the Royal Horology Collection website.

> This image accurately depicts or relates to the archive record listed above to the best of my knowledge.

The administrator workflow records this acknowledgement before upload. Once the source file and exact record association are available, the website team will upload it to the secure watch gallery, test the public zoom/fullscreen view in English and Arabic, and then mark the record’s media task complete.
